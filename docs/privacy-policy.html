Privacy Policy

Effective date: 2025-01-01  |  Extension: Yomi-Subs: Real-Time Japanese Transcription  |  Last updated: 2026-01-01

Yomi-Subs is a Chrome extension that transcribes the audio from browser tabs into Japanese text subtitles. This policy explains what data is accessed, how it is used, and what is sent outside your device.

1. Data we access

Data typePurposeStored?Sent externally?
Tab audio Transcription No — processed in memory only Only when OpenAI API mode is enabled (see §3)
OpenAI API key Authenticate to OpenAI's API In chrome.storage.sync (encrypted by Chrome) Only to api.openai.com as a request header
Extension settings User preferences In chrome.storage.sync No

2. Local mode (default)

When using Local mode, all audio is processed entirely on your own computer by a local Python server running the open-source faster-whisper library. No audio, transcription results, or any other data is transmitted to any external server or third party.

3. OpenAI Whisper API mode

When using OpenAI API mode, short audio chunks (typically 3–10 seconds) are transmitted over HTTPS to OpenAI's transcription API endpoint (https://api.openai.com/v1/audio/transcriptions) using your personal API key. Audio is processed according to OpenAI's Privacy Policy.

Your API key is never shared with the Yomi-Subs developer and is transmitted solely between your browser and OpenAI's servers.

4. Data we do NOT collect

  • We collect no analytics, crash reports, or telemetry.
  • We collect no personally identifiable information.
  • We have no backend servers of our own.
  • Transcription results are displayed on-screen for up to 6 seconds and then discarded — they are never stored or logged.
